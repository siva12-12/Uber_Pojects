# 🚖 Uber Booking Analysis – SQL & Power BI

## 📌 Project Overview

This project analyzes Uber booking data to understand ride patterns, booking performance, vehicle usage, customer behavior, payment methods, and cancellation trends.

The project uses **SQL for data analysis** and **Power BI for interactive dashboard development**.

---

## 🎯 Project Objectives

- Analyze total booking performance
- Identify the most popular vehicle types
- Analyze completed and cancelled rides
- Identify top pickup and drop locations
- Analyze payment method usage
- Understand customer and driver cancellation reasons
- Analyze customer ratings and ride distance
- Build an interactive Power BI dashboard
